# Totalidade — Canonical Identity Router

A Totalidade é a base funcional viva usada para consolidar a Kaline.

Este PR centraliza a identidade pública canônica da V27 como Kaline.

A fonte canônica da presença/vida desta identidade está em `viva.md`.

A rota autenticada padrão é:

/chat

## Núcleo visível canônico

- Chat
- Kaline Presente
- Câmara do Eco
- Calendário
- Registro Vivo
- Jardim
- Revisão
- Meu Perfil

## Motor preservado

- auth
- Supabase
- APIs existentes
- chat streaming
- persistência de mensagens
- sedimentação
- contexto vivo
- anexos úteis

O motor funcional não foi reescrito.

Rotas antigas e módulos legados continuam existindo para compatibilidade, mas não definem mais a identidade pública principal.

## K∧LINE Ledger

Este PR também registra o contrato inicial do K∧LINE Ledger / Mnemósine Ledger.
O Ledger será retrocompatível, aditivo, append-only e não bloqueante.
A implementação mínima virá em PR posterior.
